# JettoPro para o Claude

Use os seus projetos do JettoPro numa conversa com o Claude. O plugin junta o conector do JettoPro e uma orientação de
uso: o Claude consulta prazos, itens, riscos e a base de conhecimento da sua conta, e pode criar itens e projetos, mudar
estados, comentar, registrar lições, lançar horas e montar solicitações de mudança, sempre com as suas permissões no
JettoPro.

## Como usar

Instale o plugin, conecte o JettoPro na aba de conectores e autorize com a sua conta. Depois peça, por exemplo, "liste
meus projetos no JettoPro" ou "quais tarefas minhas vencem esta semana". Quando faltar algo essencial, como o método e a
data de início de um projeto novo, o Claude pergunta antes de criar.

## Dados

O plugin fala só com `https://mcp.jettopro.com.br/mcp`, que responde com o que você pode ver no JettoPro. O JettoPro não lê
as suas conversas, e o conector não apaga nada.
